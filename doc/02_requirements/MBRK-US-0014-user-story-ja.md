# US-0014 記録をファイルに書き出して戻す

- エピック：[MBRK-EP-0003](MBRK-EP-0003-epic-ja.md)
- 優先度：P3

## ストーリー

**プレイヤーとして**、ランキングの記録をファイルに保存しておき、消えてしまったときや機種を変えたときに戻したい。**ブラウザの都合で大切な記録を失わない** ようにするため。

## 受け入れ条件

- [ ] 書き出したファイルを読み込むと、同じランキングと「（あなた）」表示に戻る（§12.5-1）
- [ ] 別のアプリのファイル、新しすぎる版のファイル、壊れたファイルは、理由を表示して読み込まず、今の記録も変わらない（§12.5-2）
- [ ] score 401 + gameOver、score 390 + cleared、score 1,255 を含むファイルは「記録の内容が正しくありません」で読み込まない（§12.5-3）
- [ ] 読み込みの前に確認が出て、取り消すと何も変わらない（§12.5-4）
- [ ] ランキング画面の「記録を書き出す」で `mini-blockbreaking-game-backup-YYYYMMDD.json` が保存される（§9.6、ADR-0007）
- [ ] 読み込みに成功すると「記録を読み込みました（n 件）」が出て、表が読み直される（§9.6）
- [ ] 10 件を超える記録のファイルは上位 10 件だけを残す。`nextId` が小さすぎるときは最大 id + 1 にそろえる（§9.6）
