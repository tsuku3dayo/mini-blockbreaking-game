# US-0016 効果音をオン / オフする

- エピック：[MBRK-EP-0004](MBRK-EP-0004-epic-ja.md)
- 優先順位：15 / 21（段階 5：効果音）

## ストーリー

**プレイヤーとして**、電車の中など音を出したくない場所では、ボタン 1 つで効果音を消したい。設定は次に開いたときも覚えていてほしい。**周りを気にせず、どこでも遊べる** ようにするため。

## 受け入れ条件

- [ ] 効果音ボタンでオフにすると、以後どの出来事でも鳴らず、鳴っている音も止まる（§12.6-4）
- [ ] 効果音の設定は、アプリを開き直しても引き継がれる（§12.6-5）
- [ ] 初めて開いたときの効果音はオン（§12.6-6）
- [ ] 効果音ボタンはタイトル画面とプレイ画面の操作欄にあり、「効果音：オン」／「効果音：オフ」と文字で表示される（§8.2、§8.3、§8.7）
- [ ] プレイ中に効果音ボタンを押しても、ゲームは一時停止しない（§8.3）
- [ ] 設定を保存できない環境でも、開いている間は設定が効く（§8.7）
- [ ] 効果音ボタンは、オンかオフかを支援技術に伝える（§8.5）
