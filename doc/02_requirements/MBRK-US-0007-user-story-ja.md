# US-0007 指でパドルを動かし、タップで発射する

- エピック：[MBRK-EP-0002](MBRK-EP-0002-epic-ja.md)
- 優先順位：6 / 21（段階 2：スマホで最後まで遊べる）

## ストーリー

**スマートフォンで遊ぶプレイヤーとして**、画面を指でなぞってパドルを動かし、タップで発射したい。**片手でも直感的に、指でボールやパドルを隠さずに、思ったとおりに操作できる** ようにするため。

## 受け入れ条件

- [ ] ゲーム領域を指でなぞるとパドルが指の x に追従し、指を離すと止まる（§12.2-1）
- [ ] タッチ端末では、ゲーム領域の下に操作空間（高さ 96）が出て、そこをなぞってもパドルが指の x に追従し、タップで発射できる。パソコン（マウス）では操作空間が出ない（§12.2-2、§2、§8.3）
- [ ] 発射前に指でパドルを動かして離しても発射されず、そのあとのタップで発射される（押してから離すまでの移動が 10 px 以内ならタップ）（§12.2-3、§4.1-4）
- [ ] ゲーム領域・操作空間を指でなぞっている間、ページがスクロール・拡大しない。長押しメニュー・文字選択も出ない（§12.2-4、§4.1-7）
- [ ] 押したまま指がゲーム領域・操作空間の外に出ても、離すまで追従を続ける。その外（操作欄のボタンなど）で押した場合は追従しない（§4.1-2）
- [ ] 複数の指が触れたときは、最初に触れた指だけに従う（§4.1-2）
- [ ] OS の割り込み等でタッチが中断されたら、追従をやめる（§4.1-6）
