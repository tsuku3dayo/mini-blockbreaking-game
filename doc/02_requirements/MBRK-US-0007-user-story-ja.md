# US-0007 指でパドルを動かし、タップで発射する

- エピック：[MBRK-EP-0002](MBRK-EP-0002-epic-ja.md)
- 優先度：P1

## ストーリー

**スマートフォンで遊ぶプレイヤーとして**、画面を指でなぞってパドルを動かし、タップで発射したい。**片手でも直感的に、思ったとおりに操作できる** ようにするため。

## 受け入れ条件

- [ ] ゲーム領域を指でなぞるとパドルが指の x に追従し、指を離すと止まる（§12.2-1）
- [ ] 発射前に指でパドルを動かして離しても発射されず、そのあとのタップで発射される（押してから離すまでの移動が 10 px 以内ならタップ）（§12.2-2、§4.1-4）
- [ ] ゲーム領域を指でなぞっている間、ページがスクロール・拡大しない。長押しメニュー・文字選択も出ない（§12.2-3、§4.1-7）
- [ ] 押したまま指がゲーム領域の外に出ても、離すまで追従を続ける。ゲーム領域の外で押した場合は追従しない（§4.1-2）
- [ ] 複数の指が触れたときは、最初に触れた指だけに従う（§4.1-2）
- [ ] OS の割り込み等でタッチが中断されたら、追従をやめる（§4.1-6）
