# US-0019 新しい版に自分のタイミングで更新する

- エピック：[MBRK-EP-0005](MBRK-EP-0005-epic-ja.md)
- 優先順位：18 / 21（段階 6：アプリとして配る）

## ストーリー

**プレイヤーとして**、新しい版が出たら、遊んでいないときに自分で更新したい。今どの版かも確かめたい。**プレイ中に急に画面が読み込み直されず、更新できたかも分かる** ようにするため。

## 受け入れ条件

- [ ] 新しい版を公開しても、プレイ中に画面が切り替わらず、「更新」ボタンを押すと新しい版になる（§12.7-6）
- [ ] タイトル画面にバージョン（例：`v1.0.0`）が出る（§12.7-4、§8.2）
- [ ] バージョンの元は `package.json` の `version` の 1 か所だけ（MBRK-ADR-0002）
