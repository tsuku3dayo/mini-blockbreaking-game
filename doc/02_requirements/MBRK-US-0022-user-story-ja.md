# US-0022 ランキングの記録を全部消す

- エピック：[MBRK-EP-0003](MBRK-EP-0003-epic-ja.md)
- 優先順位：22（段階 5.5：仕様書 v1.2 の修正）

## ストーリー

**この端末で遊ぶプレイヤーとして**、ランキングの記録を全部消したい。**練習の記録を片付けて、新しい気持ちで一から記録を目指せる** ようにするため。

## 受け入れ条件

- [ ] タイトル画面に「記録を全部消す」ボタンがある（§8.2）
- [ ] 押すと確認が出る。「キャンセル」・Esc では何も変わらない（§8.2、§12.4-12）
- [ ] 確認で「消す」を選ぶと、ランキングが 0 件になり、「記録を消しました」と出る（§8.2、§12.4-12）
- [ ] 消しても、前回の名前（結果画面の名前の初期値）と効果音の設定は残る。次に登録した記録の番号は、消す前の続きから振られる（§9.2）
- [ ] 端末内保存に書き込めないときは、何も変えずに「消せませんでした。もう一度お試しください」と出る（§9.2）
