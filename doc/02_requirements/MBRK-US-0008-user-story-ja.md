# US-0008 マウス・キーボードでも遊ぶ

- エピック：[MBRK-EP-0002](MBRK-EP-0002-epic-ja.md)
- 優先度：P2

## ストーリー

**パソコンで遊ぶプレイヤーとして**、マウスやキーボードでパドルを動かし、発射したい。**スマートフォンがなくても、手元の環境で遊べる** ようにするため。

## 受け入れ条件

- [ ] マウス・← → / A D でもパドルを動かせ、最後に使った入力に従う（§12.2-4）
- [ ] Space の押しっぱなしで連続発射されない（§12.2-5）
- [ ] キーボードでの移動は 420 px/秒で、両方押しでは止まる。キー配列・IME の状態に左右されない（§4.1-1、§4）
- [ ] マウスはボタンを押さなくても動かせば追従し、ゲーム領域の外にあっても追従する（§4.1-2）
- [ ] ゲーム領域をクリックすると発射できる（動かしながらのクリックは発射しない）（§4.1-4）
- [ ] ゲーム中は ← → Space でページがスクロールしない（§4.1-7）
- [ ] マウスで操作しているときは、ゲーム中のゲーム領域上のマウスカーソルが消える（§2.2）
- [ ] ウィンドウがフォーカスを失ったら、押していたキーを離した扱いにする（§4.1-6）
