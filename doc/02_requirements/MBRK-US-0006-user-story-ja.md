# US-0006 結果とスコアの内訳を見る

- エピック：[MBRK-EP-0001](MBRK-EP-0001-epic-ja.md)
- 優先順位：8 / 21（段階 2：スマホで最後まで遊べる）

## ストーリー

**プレイヤーとして**、ゲームが終わったら、合計スコアと、その内訳（ブロック得点・時間ボーナス・タイム）を見たい。そこからすぐにもう一度遊びたい。**どうすれば点が伸びるかが分かり、続けて挑戦できる** ようにするため。

## 受け入れ条件

- [ ] 95,789 ms でクリアすると、ブロック 400、時間ボーナス 850、合計 1,250、タイム 95.7 秒と表示される（§12.3-1）
- [ ] 180 秒以上かかったクリアの時間ボーナスが 0（§12.3-2）
- [ ] ゲームオーバーの合計がブロック得点と等しく、時間ボーナス・タイムの行が出ない（§12.3-3）
- [ ] 見出しはクリアなら「CLEAR!」（成功色・アイコン）、ゲームオーバーなら「GAME OVER」（エラー色・アイコン）。壊したブロックは `n / 40` で出る（§8.3）
- [ ] 結果パネルは暗くしたゲーム領域の上に重ねて出る。収まらないときはパネルの中をスクロールできる（§8.3）
- [ ] RETRY で新しいゲーム（発射前）、TITLE でタイトル、RANKING でランキング画面になる（§7.1、§7.2）
- [ ] 数値は 3 桁区切りで表示される（§6）

## 補足

- 結果パネルのスコア登録は US-0012、入力ガードは US-0011 で扱う。
