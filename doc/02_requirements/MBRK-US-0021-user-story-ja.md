# US-0021 画面の読み上げで状況が分かる

- エピック：[MBRK-EP-0002](MBRK-EP-0002-epic-ja.md)
- 優先順位：21 / 21（段階 7：仕上げ）

## ストーリー

**画面の読み上げ機能やキーボードを使うプレイヤーとして**、スコア・一時停止・結果を読み上げで知り、ボタンをキーボードで操作したい。**見え方や使う道具が違っても、ゲームの状況が分かり、遊べる** ようにするため。

## 受け入れ条件

- [ ] ゲーム領域に「ブロック崩しのゲーム画面」という代替テキストがある（§8.5）
- [ ] スコアが変わると「スコア 120」、一時停止で「一時停止しました。再開ボタンで再開します」、再開で「再開しました」、終了で「クリア。スコア 1,250」／「ゲームオーバー。スコア 120」と読み上げられる（画面上には出さない）（§8.5）
- [ ] 一時停止ボタン・効果音ボタンは、押された状態を支援技術に伝える（§8.5）
- [ ] 効果音で知らせる出来事は、画面表示か読み上げでも分かる（§8.5）
- [ ] 結果（クリア / ゲームオーバー）や自分の記録は、色だけでなく文字・アイコンでも区別できる（§8.4）
- [ ] すべてのボタンをキーボードで操作でき、フォーカス位置が見える（§8.1）
- [ ] 端末で「視差効果を減らす」が有効なときは、装飾的なアニメーションが動かない（§8.1）
