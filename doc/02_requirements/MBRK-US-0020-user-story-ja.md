# US-0020 起動できなくなっても自動で直る

- エピック：[MBRK-EP-0005](MBRK-EP-0005-epic-ja.md)
- 優先度：P3

## ストーリー

**プレイヤーとして**、更新の途中などでアプリが起動しなくなっても、自分で難しい操作をせずに直ってほしい。直すときに記録が消えないでほしい。**仕組みを知らなくても、ずっと遊び続けられる** ようにするため。

## 受け入れ条件

- [ ] 起動に失敗したら、このアプリの Service Worker とキャッシュだけを消して読み込み直す。1 回目は自動、2 分以内の 2 回目は「なおす」ボタンを出す（§8.6、simple_shogi の `public/boot.js` と同じ動き）
- [ ] 直す処理でランキング・前回の名前・効果音の設定が消えない（§8.6）
- [ ] 同じサイトに載るほかのアプリのキャッシュを消さない（ADR-0007）
- [ ] `npm run check:dist` が起動の見張りの仕組みを確認して通る
