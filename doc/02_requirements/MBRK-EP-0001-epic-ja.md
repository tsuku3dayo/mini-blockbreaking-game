# EP-0001 ブロック崩しを遊ぶ

## 目的

プレイヤーが、タイトル画面から始めて、ボールを打ち返してブロックを壊し、クリアかゲームオーバーまで遊び、結果を見られるようにする。アプリの中心になる機能。

## 範囲

- タイトル画面と画面の切替え
- フィールド・パドル・ボール・ブロックの初期配置と描画、HUD
- 物理（固定タイムステップ、発射、壁・パドル・ブロックとの衝突、最小垂直成分、加速）
- スコア（ブロック得点・時間ボーナス・合計）と終了の判定
- 結果パネル（スコアの内訳と RETRY / TITLE / RANKING。登録は EP-0003）

含めないもの：操作の細則（EP-0002）、登録とランキング（EP-0003）、効果音（EP-0004）。
