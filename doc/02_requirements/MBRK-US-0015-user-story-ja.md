# US-0015 効果音で出来事が分かる

- エピック：[MBRK-EP-0004](MBRK-EP-0004-epic-ja.md)
- 優先順位：14 / 21（段階 5：効果音）

## ストーリー

**プレイヤーとして**、打ち返したとき・壊したとき・速くなったとき・終わったときに音で知らせてほしい。**画面のボールを見ながらでも出来事が分かり、手ごたえを感じられる** ようにするため。

## 受け入れ条件

- [ ] 発射・パドル・壁・ブロック・加速・クリア・ゲームオーバー・登録成功で、それぞれの効果音が鳴る（§12.6-1）
- [ ] 2 個のブロックを同時に壊しても、ブロックの音は 1 回だけ鳴る（§12.6-2）
- [ ] 最後のブロックを壊したステップでは、クリアの音だけが鳴る（§12.6-3）
- [ ] 音の機能が使えない環境でも、ゲームを最後まで遊べる（§12.6-7）
- [ ] ブロックの音は行ごとに高さが変わり、上の行ほど高い（§8.7）
- [ ] パドルに押し出されただけ（上向きのボール）では、パドルの音は鳴らない（§8.7）
- [ ] 1 フレームで同じ種類の音は 1 回だけ鳴る（§8.7）
- [ ] 一時停止・画面の非表示で、鳴っている音が止まる（§8.7）
- [ ] スマートフォンでも、最初のタップ（START 等）のあとから音が鳴る（§8.7）
- [ ] 出来事から音が鳴るまでの遅れを感じない（目安 50 ms 以内）（§10）
