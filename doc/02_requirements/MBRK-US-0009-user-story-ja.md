# US-0009 一時停止・再開する

- エピック：[MBRK-EP-0002](MBRK-EP-0002-epic-ja.md)
- 優先順位：9 / 21（段階 3：中断・誤操作に強くする）

## ストーリー

**プレイヤーとして**、電話や通知などで手が離れるときにゲームを止め、あとで同じところから続けたい。**急な中断でボールを落としたり、タイムを損したりしない** ようにするため。

## 受け入れ条件

- [ ] 一時停止ボタン・P / Esc で一時停止・再開でき、一時停止中は TIME が増えない（§12.2-6）
- [ ] 別のアプリやタブに切り替えると自動で一時停止し、戻っても自動では再開しない（§12.2-7）
- [ ] 一時停止中に Space を押しても、再開した瞬間に発射されない（§12.2-8）
- [ ] 一時停止中は半透明の幕と「PAUSED」「再開ボタン / P / Esc で再開」が出る（§2.2）
- [ ] 一時停止ボタンの表示は「一時停止」⇔「再開」に切り替わる。押せるのは発射前・プレイ中・一時停止中だけ（§8.3）
- [ ] 再開すると、止める前の状態（発射前 / プレイ中）に戻り、止まっていた時間は進まない（§5.1、§7.1）
- [ ] P / Esc の押しっぱなしで一時停止と再開が繰り返されない（§4.1-5）
