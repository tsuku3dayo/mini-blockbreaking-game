# US-0023 クレジットを見る

- エピック：[MBRK-EP-0001](MBRK-EP-0001-epic-ja.md)
- 優先順位：23（段階 7：仕上げ、仕様書 v1.3 で追加）

## ストーリー

**プレイヤーとして**、このゲームを誰が作ったかを見たい。**作った人の名前と役割が分かる** ようにするため。

## 受け入れ条件

- [ ] タイトル画面の RANKING の下に「クレジット」ボタンがある（§8.2）
- [ ] 押すとクレジット画面になり、ページタイトルは「ブロック崩し - クレジット」、見出し「クレジット」に初期フォーカスがある（§8、§8.8）
- [ ] §8.8 の 6 つの役職と名前が、上から順に中央揃えで表示される。文字として表示され、読み上げで読める（§8.8、§12.7-7）
- [ ] BACK ボタン・Esc でタイトル画面に戻る（§4、§8.8）
- [ ] 横スクロールが出ない。ボタンは 44 px 以上（§8.1）
