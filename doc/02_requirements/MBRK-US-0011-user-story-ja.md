# US-0011 結果画面での誤操作を防ぐ

- エピック：[MBRK-EP-0002](MBRK-EP-0002-epic-ja.md)
- 優先順位：10 / 21（段階 3：中断・誤操作に強くする）

## ストーリー

**プレイヤーとして**、ゲームが終わった瞬間に、プレイ中の指やキーの勢いでリトライや登録が動いてほしくない。**結果を確かめる前に画面が進んでしまう失敗を防ぐ** ため。

## 受け入れ条件

- [ ] 結果画面の表示から 500 ms 以内の Enter・Space・タップではリトライ・登録が動かない（§12.2-9）
- [ ] 500 ms を過ぎれば、Enter・Space・タップが普通に効く（§4.1-8）
- [ ] タイトル・結果画面で、ボタンや入力欄にフォーカスがあるときの Enter は、その部品の動作だけを行い、画面全体の Enter（開始・リトライ）は動かない（§4.1-9）
- [ ] ゲームが終わったら、ゲーム用の入力（スクロールの抑止等）が結果画面の操作を妨げない（§4.1-7）
