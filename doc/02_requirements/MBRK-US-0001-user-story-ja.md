# US-0001 タイトル画面からゲームを始める

- エピック：[MBRK-EP-0001](MBRK-EP-0001-epic-ja.md)
- 優先度：P1

## ストーリー

**プレイヤーとして**、アプリを開いたらタイトル画面で操作方法を確かめ、すぐにゲームを始めたい。**説明を読まなくても遊び方が分かり、待たずに遊べる** ようにするため。

## 受け入れ条件

- [ ] 起動するとタイトル画面が出て、見出し「BREAKOUT」、START ボタン、RANKING ボタン、操作方法の一覧（パドル移動・発射・一時停止）が表示される（§8.2）
- [ ] START を押すと、新しいゲームの発射前の状態でプレイ画面になる（§7.1）
- [ ] PC では START に初期フォーカスがあり、Enter でも始められる（§4、§8.2）
- [ ] RANKING を押すとランキング画面になる（§8）
- [ ] 画面ごとにページタイトルが変わる（「ブロック崩し - タイトル」等）（§8）
- [ ] 存在しない画面を指定して開くと、タイトル画面になる（§8）

## 補足

- バージョン表示とインストール方法の入口は US-0017・US-0019、効果音ボタンは US-0016 で扱う。
