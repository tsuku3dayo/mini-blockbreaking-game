# US-0005 クリア・ゲームオーバーで終わる

- エピック：[MBRK-EP-0001](MBRK-EP-0001-epic-ja.md)
- 優先順位：4 / 21（段階 1：ゲームの芯）

## ストーリー

**プレイヤーとして**、全部壊したらクリア、落としたらゲームオーバーと、はっきり決着がついてほしい。結果はいつも公平であってほしい。**勝ち負けに納得でき、腕を磨けば必ず結果に表れる** ようにするため。

## 受け入れ条件

- [ ] 40 個壊すとクリア、ボールが下端の外に出るとゲームオーバー（§12.1-10）
- [ ] 最後のブロックを壊したステップでボールが下端の外に出ても、クリアになる（§12.1-11）
- [ ] 同じ入力列から同じ結果になる（乱数がない）（§12.1-12）
- [ ] 表示のフレームレートが変わっても、物理は 1/120 秒刻みで同じ結果になる。1 フレームで進める時間は最大 100 ms（§5.1、§10）
- [ ] 終了すると物理が止まり、最後の盤面が暗く（不透明度 50%）表示され続ける（§7.1）
- [ ] HUD の TIME は、プレイ中だけ増える経過秒（切り捨て）を表示する（§6）
