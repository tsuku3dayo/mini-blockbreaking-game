# US-0002 ボールを発射する

- エピック：[MBRK-EP-0001](MBRK-EP-0001-epic-ja.md)
- 優先度：P1

## ストーリー

**プレイヤーとして**、ゲームの始めにパドルの位置を決めてから、自分のタイミングでボールを発射したい。**落ち着いて狙いを付けてから始められる** ようにするため。

## 受け入れ条件

- [ ] 開始直後、パドル中心 x = 240、ボール中心 (240, 593)、ブロック 40 個、得点 0、TIME 0（§12.1-1）
- [ ] 発射前はボールがパドルに乗って追従し、TIME が増えない（§12.1-2）
- [ ] 発射直後の速度が約 (102.61, −281.91) px/秒（垂直から右へ 20°、速さ 300）（§12.1-3）
- [ ] フィールド（480 × 640、HUD 帯 48）、8 列 × 5 行のブロック（行ごとの色）、パドル、ボール、HUD（SCORE・TIME）が仕様書の位置に描かれる（§2、§3）
- [ ] 発射前は「タップ / Space で発射」のヒントが出る（§2.2）

## 補足

- 発射の操作（タップ・クリック・Space）の細則は US-0007・US-0008 で扱う。
