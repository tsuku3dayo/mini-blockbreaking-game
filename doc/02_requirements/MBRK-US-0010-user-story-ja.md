# US-0010 スマートフォンの画面に合った大きさで遊ぶ

- エピック：[MBRK-EP-0002](MBRK-EP-0002-epic-ja.md)
- 優先度：P1

## ストーリー

**スマートフォンで遊ぶプレイヤーとして**、自分の画面の大きさにちょうど収まった表示で遊びたい。**スクロールせずにフィールド全体を見ながら、くっきりした画面で遊べる** ようにするため。

## 受け入れ条件

- [ ] 幅 375 × 高さ 667（iPhone SE 相当）と幅 412 × 高さ 915（Pixel 7 相当）の縦画面で、横スクロールやはみ出しがなく、ゲーム領域と一時停止ボタンが 1 画面に収まる（§12.7-1）
- [ ] 結果画面で名前を入力するためにソフトウェアキーボードが出ても、ゲーム領域の大きさが変わらない（§12.7-2）
- [ ] タップできる部品がすべて 44 px 以上（§12.7-3）
- [ ] ゲーム領域は 3:4 を保ち、表示幅は §2.1 の式で決まる（最小 288 × 384、最大 448 × 約 597）。画面の大きさや向きが変わるとすぐに合わせ直す（§2.1）
- [ ] 高密度画面でもぼやけない（§2.1）
- [ ] ノッチ・ホームバーの領域に内容が入り込まない（§8.1）
- [ ] 横向きで、ゲーム領域が最小サイズでしか出せないときは「縦向きでのプレイをおすすめします」と表示する（§8.1）
