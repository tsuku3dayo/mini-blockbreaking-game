# US-0018 電波がなくても遊ぶ

- エピック：[MBRK-EP-0005](MBRK-EP-0005-epic-ja.md)
- 優先順位：17 / 21（段階 6：アプリとして配る）

## ストーリー

**プレイヤーとして**、地下鉄や機内モードのときでも、いつもどおり遊んで記録を残したい。**電波の状況に関係なく、すき間時間に遊べる** ようにするため。

## 受け入れ条件

- [ ] 一度開いたあと、通信を切っても起動・プレイ・登録・ランキング表示ができる（§12.7-5）
- [ ] 外部のリソース（Web フォント・外部のスクリプト等）を読み込まない（§8.6）
- [ ] アプリから外部へデータを送らない（§1.2、§10）
