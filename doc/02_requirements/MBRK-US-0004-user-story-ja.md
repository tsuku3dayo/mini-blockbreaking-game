# US-0004 ブロックを壊して得点する

- エピック：[MBRK-EP-0001](MBRK-EP-0001-epic-ja.md)
- 優先順位：3 / 21（段階 1：ゲームの芯）

## ストーリー

**プレイヤーとして**、ボールをブロックに当てて壊し、得点が増えていくのを見たい。進むほどボールが速くなってほしい。**壊す気持ちよさと、だんだん難しくなる緊張感を味わえる** ようにするため。

## 受け入れ条件

- [ ] ブロックに当たると 1 回で壊れて消え、1 個 10 点が HUD の SCORE に加わる（§3.3、§6）
- [ ] 2 個のブロックに同時に触れたら 2 個とも壊れ、20 点入り、反射は 1 回だけ（§12.1-7）
- [ ] 10・20・30 個目を壊した時点で速さが 330・360・390 px/秒になり、向きは変わらない（§12.1-8）
- [ ] ブロックの側面に当たれば横に、上下の面に当たれば縦に、角に当たれば両方に跳ね返る（§5.6）
- [ ] HUD の SCORE は 3 桁区切りで表示される（§6）
