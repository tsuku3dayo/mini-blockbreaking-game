# US-0003 ボールを打ち返し、壁で跳ね返らせる

- エピック：[MBRK-EP-0001](MBRK-EP-0001-epic-ja.md)
- 優先順位：2 / 21（段階 1：ゲームの芯）

## ストーリー

**プレイヤーとして**、パドルのどこで打つかでボールの飛ぶ向きを変えたい。**狙ったブロックを自分の腕で壊しに行ける** ようにするため。

## 受け入れ条件

- [ ] パドル中央で打ち返すと真上、端で打ち返すと垂直から 60° に飛ぶ（打ち返す前の向き・速さによらない）（§12.1-4、§5.5）
- [ ] 左右の壁と天井（y = 48）で跳ね返り、下端では跳ね返らない（§12.1-5）
- [ ] パドルを左右の壁より外に出せない（中心 40–440）（§12.1-6）
- [ ] ボールの垂直成分の大きさが常に速さの 0.5 倍以上（ほぼ水平に飛び続けない）（§12.1-9）
- [ ] パドルの側面・角に当たったときは横に跳ね返り、上下の速さは変わらない（§5.5-B）
- [ ] 壁の近くでボールが小刻みに反転し続けない（向きを絶対値で決める）（§5.4）
