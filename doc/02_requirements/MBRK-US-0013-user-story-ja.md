# US-0013 ランキングで自分の記録を見る

- エピック：[MBRK-EP-0003](MBRK-EP-0003-epic-ja.md)
- 優先順位：13 / 21（段階 4：記録を残す）

## ストーリー

**プレイヤーとして**、これまでの上位の記録を一覧で見て、さっきの記録がどこに入ったかを確かめたい。**自己ベストと比べて、次の目標を決められる** ようにするため。

## 受け入れ条件

- [ ] 同点の記録は先に登録した方が上位になり、登録時に表示する順位とランキング画面の順位が一致する（§12.4-4）
- [ ] ランキング画面で直前に登録した記録に「（あなた）」が付き、背景色と左端の帯で強調される（§12.4-8、§8.4）
- [ ] 0 件のとき「まだ記録がありません」+「タイトルへ戻る」、読み込めないとき「ランキングを読み込めませんでした」+「再読み込み」が出る（§12.4-10）
- [ ] 上位 10 件が、順位 / 名前 / スコア / 結果 / 登録日時の列で並ぶ。1〜3 位は「1st」「2nd」「3rd」を強調色で出す（§8.4）
- [ ] 長い名前は省略記号で切られ、全文を長押し・ツールチップ等で見られる（§8.4）
- [ ] 結果は「CLEAR」「GAME OVER」を色だけでなくアイコンと文字で区別する。登録日時は端末のタイムゾーンで `YYYY/MM/DD HH:mm`（§8.4）
- [ ] 幅 375 の画面でも横スクロールが出ない（§8.4）
- [ ] BACK ボタンまたは Esc でタイトルへ戻る。見出しに初期フォーカスがある（§8.4）
- [ ] 画面を開くたびに最新の記録を読み直す（§8.4）
