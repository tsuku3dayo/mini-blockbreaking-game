# GUI-0003 プレイ画面

## 1. 画面の形

### 1.1 幅 375 × 高さ 667（iPhone SE 相当、タッチ端末）

```
┌─────────────────────────────────────┐
│ ↕ 24（上端の余白）                  │
│ ┌─────────────────────────────────┐ │ ─┬─
│ │ SCORE : 300           TIME : 42 │ │  │
│ ├─────────────────────────────────┤ │  │
│ │  ▬ ▬ ▬ ▬ ▬ ▬ ▬ ▬               │ │  │
│ │  ▬ ▬ ▬ ▬ ▬ ▬ ▬ ▬               │ │  │ ゲーム領域
│ │  ▬ ▬ ▬ ▬ ▬ ▬ ▬ ▬               │ │  │ 343 × 457
│ │  ▬ ▬ ▬ ▬ ▬ ▬ ▬ ▬               │ │  │（Canvas）
│ │  ▬ ▬ ▬ ▬ ▬ ▬ ▬ ▬               │ │  │
│ │                                 │ │  │
│ │               ●                 │ │  │
│ │                                 │ │  │
│ │            ▀▀▀▀▀▀               │ │  │
│ │                                 │ │  │
│ └─────────────────────────────────┘ │ ─┴─
│ ↕ 8                                 │
│ ┌─────────────────────────────────┐ │ ─┬─
│ │                                 │ │  │ 操作空間
│ │ ここをなぞって移動・タップで発射│ │  │ 343 × 96
│ │                                 │ │  │
│ └─────────────────────────────────┘ │ ─┴─
│ ↕ 8                                 │
│ [⏸ 一時停止]        [🔊 効果音：オン] │ ← 操作欄（高さ 48）
│ ↕ 16（下端の余白）                  │
└─────────────────────────────────────┘
 使う高さ：24 + 457 + 8 + 96 + 8 + 48 + 16 = 657（667 に収まる）
```

パソコン（マウス）では操作空間を出さず、ゲーム領域の下はすぐ操作欄になる（v1.1 までと同じ）。

### 1.2 表示サイズの計算（仕様書 §2.1）

| 画面（CSS px） | 操作空間 | 利用可能幅 | 利用可能高さ | 表示（幅 × 高さ） | 倍率 |
| --- | --- | --- | --- | --- | --- |
| 375 × 667（iPhone SE、E2E） | あり | 343 | 667 − 24 − 104 − 56 − 16 = 467 | 343 × 457 | 0.71 |
| 375 × 548（iPhone SE の Safari、ツールバーあり） | あり | 343 | 348 | 288 × 384（最小） | 0.60 |
| 412 × 839（Pixel 7、E2E の表示領域） | あり | 380 | 639 | 380 × 506 | 0.79 |
| 1280 × 800（パソコン） | なし | 448 | 704 | 448 × 597 | 0.93 |

- 「操作空間の高さ」は、ゲーム領域との間 8 + 操作空間 96 = 104 として計算する（タッチ端末だけ）。「操作欄の高さ」は、間 8 + ボタン 48 = 56。
- iPhone SE の Safari（ツールバーあり、表示領域の高さ 548）では、ゲーム領域が最小の 288 × 384 になり、全体（584）が表示領域に収まらず少し縦にスクロールする。ホーム画面に追加したアプリ（高さ 667）では収まる。
- 表示幅は整数 px に切り捨てる（にじみを防ぐため）。表示高さ = 表示幅 × 4/3（切り捨て）。

## 2. 要素

### 2.1 ゲーム領域（Canvas）

| 項目 | 内容 |
| --- | --- |
| 中身 | 仕様書 §2.2 の描画順で、フィールド・外枠・ブロック・パドル・ボール・HUD・オーバーレイを描く（色は GUI-0001 §3） |
| 代替テキスト | `role="img"`、`aria-label="ブロック崩しミニのゲーム画面"` |
| フォーカス | `tabindex="0"`。プレイ画面を開いたら、ここにフォーカスを移す。フォーカスの輪は Canvas の外枠の外側に出す |
| タッチ | `touch-action: none`、`user-select: none`、`-webkit-touch-callout: none`（なぞってもスクロール・拡大・長押しメニューが出ない。仕様書 §4.1-7） |
| マウス | プレイ中はカーソルを隠す（`cursor: none`）。発射前・一時停止中・終了後は通常のカーソル |
| 中央寄せ | `main` の中で左右中央 |

### 2.2 オーバーレイ（Canvas の中に描く）

| 状態 | 描くもの |
| --- | --- |
| 発射前 | 「タップ / Space で発射」（`--muted`、14、中央より 80 下） |
| 一時停止中 | 全面に `--pause-veil` の幕、「PAUSED」（太字 28、中央）、「再開ボタン / P / Esc で再開」（14、中央より 36 下） |
| 終了後 | 盤面全体を不透明度 50% で描く（その上に結果パネルを DOM で重ねる。GUI-0004） |

### 2.3 操作空間（タッチ端末だけ）

ゲーム領域のすぐ下（間 8）に、ゲーム領域と同じ幅・高さ 96 の箱を置く（仕様書 §2）。

| 項目 | 内容 |
| --- | --- |
| 出す条件 | `matchMedia('(pointer: coarse)')` が真のとき（主な入力が指の端末）。偽（マウス）のときは出さず、場所も取らない |
| 見た目 | 地 `--surface`、枠 `--border`（線幅 1）、角丸 10。中央に「ここをなぞって移動・タップで発射」（`--muted`、14） |
| 操作 | なぞるとパドルが指の x に追従し、タップ（10 px 以内）で発射（仕様書 §4.1）。横方向の位置はゲーム領域と同じ変換で論理座標に直す（箱とゲーム領域は左右の端がそろっている） |
| タッチ | ゲーム領域と同じく `touch-action: none`、`user-select: none`、`-webkit-touch-callout: none` |
| 読み上げ | 飾りと同じ扱い（`aria-hidden="true"`）。操作はゲーム領域・キーボードでもできるため |
| 終了後 | 結果パネル（クリア・ゲームオーバー）を出している間は、操作空間を出さない（ゲーム用の入力を受け付けないため。仕様書 §4.1-7）。ゲーム領域の大きさはプレイ中と同じにし、操作欄が上に詰まる。RETRY で新しいゲームになったら、また出す |

### 2.4 操作欄

操作空間（パソコンではゲーム領域）のすぐ下に、左右に分けて 2 つのボタンを置く。

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 一時停止ボタン（左） | トグルボタン。一時停止していないとき「一時停止」+ pause、一時停止中は「再開」+ play。`aria-pressed` は一時停止中に `true`。押せるのは発射前・プレイ中・一時停止中。終了後は押せない | US-0009 |
| 効果音ボタン（右） | タイトル画面と同じ部品（GUI-0002）。押してもゲームは止まらない | US-0016 |

- 操作欄のボタンを指で押したあとも、ゲームのキー操作が効くよう、押し終わったらゲーム領域にフォーカスを戻す。
- 操作欄のボタンに触れても、パドルは動かず、発射もしない（ゲーム領域・操作空間の外で押したため。仕様書 §4.1-2）。

## 3. 状態ごとの見え方

| 状態 | ゲーム領域 | 操作空間（タッチ端末） | 一時停止ボタン | 結果パネル |
| --- | --- | --- | --- | --- |
| 発射前 | 発射のヒント | 出す | 「一時停止」・押せる | なし |
| プレイ中 | 通常 | 出す | 「一時停止」・押せる | なし |
| 一時停止 | 幕 + PAUSED | 出す | 「再開」・押せる | なし |
| クリア / ゲームオーバー | 不透明度 50% | 出さない | 「一時停止」・押せない | あり（GUI-0004） |

## 4. 読み上げ

| きっかけ | 通知領域に出す文（仕様書 §8.5） |
| --- | --- |
| ブロック得点が変わった | 「スコア 120」（1 フレームに 1 回まで） |
| 一時停止 | 「一時停止しました。再開ボタンで再開します」 |
| 再開 | 「再開しました」 |
| クリア / ゲームオーバー | 「クリア。スコア 1,250」／「ゲームオーバー。スコア 120」 |

## 5. 横向きのとき

横向きで、ゲーム領域が最小（288 × 384）でしか出せないときは、ゲーム領域の上に 1 行の案内（GUI-0006 §5）を出す。ゲームはそのまま遊べ、縦スクロールで全体を見られる。
