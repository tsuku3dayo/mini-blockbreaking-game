# GUI-0004 結果パネル

ゲームが終わったら、暗くしたゲーム領域の上に重ねて出す（GUI-0003）。パネルの大きさはゲーム領域と同じで、内側に余白 16 を取る。収まらないときはパネルの中を縦にスクロールする。

## 1. パネルの形（ゲーム領域 343 × 457 のとき）

### 1.1 クリア

```
┌───────────────────────────────────┐
│          ✔ CLEAR!                 │ ← 見出し（--success、太字 28、アイコン付き）
│ ─────────────────────────────────  │
│  ブロック             400         │
│  時間ボーナス         850         │
│  タイム              95.7 秒      │
│  壊したブロック      40 / 40      │
│ ─────────────────────────────────  │
│  合計             1,250           │ ← 大きく（太字 32、--accent）
│ ─────────────────────────────────  │
│  名前を登録                        │
│  ┌─────────────────┐ ┌─────────┐  │
│  │ TSUKU           │ │REGISTER │  │ ← 入力欄 + 主ボタン（横並び）
│  └─────────────────┘ └─────────┘  │
│  1〜12 文字                 5 / 12 │ ← 補助の文字 / 文字数
│                                   │ ← 結果のメッセージ（1 行分の場所を取っておく）
│  ┌─────────┐┌────────┐┌─────────┐ │
│  │ RETRY ⏎ ││ TITLE  ││ RANKING │ │ ← 3 つのボタン（横並び）
│  └─────────┘└────────┘└─────────┘ │
└───────────────────────────────────┘
```

### 1.2 ゲームオーバー

```
┌───────────────────────────────────┐
│          ✖ GAME OVER              │ ← 見出し（--danger、太字 28、アイコン付き）
│ ─────────────────────────────────  │
│  壊したブロック      12 / 40      │
│ ─────────────────────────────────  │
│  合計               120           │ ← 大きく（太字 32、--accent）
│ ─────────────────────────────────  │
│  名前を登録  …（クリアと同じ）     │
│  RETRY / TITLE / RANKING          │
└───────────────────────────────────┘
```

ゲームオーバーでは「ブロック」「時間ボーナス」「タイム」の行を出さない（仕様書 §8.3、§12.3-3）。

## 2. 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 見出し | `h2`。クリア：check-circle +「CLEAR!」（`--success`）。ゲームオーバー：x-circle +「GAME OVER」（`--danger`） | US-0006 |
| 内訳 | 定義リスト（`dl`）。項目名は左寄せ・`--muted`、数値は右寄せ・等幅。3 桁区切り | US-0006 |
| タイム | 経過秒を小数第 1 位で切り捨て +「秒」（例：95,789 ms →「95.7 秒」） | US-0006 |
| 合計 | 太字 32、`--accent`。3 桁区切り | US-0006 |
| 名前の入力欄 | ラベル「名前を登録」。`maxlength` は付けない（コードポイントで数えるため。超えたらエラーを出す）。初期値は前回の名前 | US-0012 |
| REGISTER | 主ボタン。規則を満たさない間・登録済みの間は押せない | US-0012 |
| 補助の文字 | 左に「1〜12 文字」、右に `現在の文字数 / 12`。エラーのときは左を エラー文に替え、`--danger` にする | US-0012 |
| 結果のメッセージ | `role="status"`。成功・失敗を出す（§3）。出ていないときも 1 行分の高さを取っておき、出たときにボタンの位置がずれないようにする | US-0012 |
| RETRY | 主ボタン。PC では `Enter` のヒント。新しいゲームでプレイ画面へ | US-0006 |
| TITLE | 普通のボタン。タイトル画面へ | US-0006 |
| RANKING | 普通のボタン。ランキング画面へ | US-0006 |

- 3 つのボタンは横に等分して並べる（幅 343 − 32 = 311 を 3 等分、間隔 8 → 各 約 98）。文字が入りきらないときは 2 段に折り返す。
- 入力欄と REGISTER も横に並べる（REGISTER は幅 112 固定、残りが入力欄）。

## 3. 登録の状態

| 状態 | 入力欄 | REGISTER | メッセージ |
| --- | --- | --- | --- |
| 入力前・入力中（規則どおり） | 入力できる | 押せる | なし |
| 規則違反 | エラーの枠 | 押せない | 補助の文字にエラー文（仕様書 §9.3 の文） |
| 空（一度離れたあと） | エラーの枠 | 押せない | 「名前を入力してください」 |
| 登録成功（10 位以内） | 押せない | 押せない | check-circle +「n 位で登録しました」（`--success`） |
| 登録成功（ランキング外） | 押せない | 押せない | 「ランキング外でした（上位 10 件に入りませんでした）」（`--muted`） |
| 保存の失敗 | 入力できる | 押せる | x-circle +「保存できませんでした。もう一度お試しください」（`--danger`） |

- 空のエラーは、一度入力欄からフォーカスが外れたあとにだけ出す（仕様書 §9.5）。
- 保存は端末の中で一瞬で終わるので、「登録中…」の表示は設けない。
- 成功したら RETRY にフォーカスを移す。

## 4. フォーカスとキー操作

| 場面 | 動き |
| --- | --- |
| パネルが出たとき（PC：`(hover: hover) and (pointer: fine)`） | 名前の入力欄にフォーカスし、カーソルを末尾に置く |
| パネルが出たとき（スマホ） | 見出しにフォーカスする（`tabindex="-1"`）。ソフトウェアキーボードを出さない |
| 入力欄で Enter | 登録する（REGISTER と同じ。押せないときは何もしない）。RETRY は動かさない（仕様書 §4.1-9） |
| ボタンで Enter | そのボタンの動作だけ |
| どこにもフォーカスがないときの Enter | RETRY と同じ |
| Tab の順 | 入力欄 → REGISTER → RETRY → TITLE → RANKING |

## 5. 入力ガード（仕様書 §4.1-8）

- パネルが出てから 500 ms の間は、Enter・Space と、パネル上のタップ・クリックを無視する。
- 見た目は変えない（ボタンを押せない見た目にはしない。500 ms は短く、ちらつくため）。

## 6. 読み上げ

- パネルが出たとき、通知領域に「クリア。スコア 1,250」／「ゲームオーバー。スコア 120」を出す（GUI-0003 §4）。
- パネルは `role="region"`、`aria-labelledby` で見出しを結ぶ。
