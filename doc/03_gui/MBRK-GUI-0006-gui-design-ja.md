# GUI-0006 ダイアログと通知

ダイアログは `<dialog>` 要素を `showModal()` で開く（背面を操作できなくし、Esc で閉じられるようにするため）。見た目は地 `--surface`、枠 `--border`、角丸 12、最大幅 343（画面幅 − 32）、背面は `rgb(0 0 0 / 0.6)`。開いたら最初のボタンにフォーカスし、閉じたら開いたボタンにフォーカスを戻す。

## 1. インストール方法のダイアログ（US-0017）

`simple_shogi` の `#install-dialog` を流用し、文言をこのアプリに合わせる。

```
┌───────────────────────────────────┐
│ アプリとしてインストールする方法   │ ← 見出し
│                                   │
│ [ 今すぐインストール ]             │ ← 主ボタン（使えるブラウザのときだけ）
│                                   │
│ ▼ iPhone / iPad（Safari）          │ ← 今の端末の項目を最初から開く（details）
│    1. 下の共有ボタンを押す         │
│    2.「ホーム画面に追加」を選ぶ    │
│    3.「追加」を押す                │
│ ▶ Android（Chrome）                │
│ ▶ パソコン（Chrome / Edge）        │
│                                   │
│ ホーム画面から開くと、電波がなく   │
│ ても遊べます。                     │
│                          [ 閉じる ]│
└───────────────────────────────────┘
```

- 3 つの手順は `details` / `summary` で開閉する。今の端末の項目に `open` を付ける。
- 「今すぐインストール」は、`beforeinstallprompt` を受け取れたときだけ出す。

## 2. 記録の読み込みの確認（US-0014）

ファイルを選んだあと、読み込む前に出す。

```
┌───────────────────────────────────┐
│ 記録を読み込みますか？             │
│                                   │
│ 今の記録は置き換わります。読み込み │
│ ますか？                           │
│                                   │
│ [ キャンセル ]      [ 読み込む ]   │
└───────────────────────────────────┘
```

- 「キャンセル」は普通のボタンで、最初のフォーカスを置く（誤って置き換えないため）。「読み込む」は主ボタン。
- Esc・キャンセルで閉じたら、何も変えない。
- ファイルの中身に問題があるとき（仕様書 §9.6 の表）は、確認を出さずに、ランキング画面の結果のメッセージにエラーを出す。

### 2.1 記録の全消去の確認（US-0022）

タイトル画面の「記録を全部消す」を押したときに出す。

```
┌───────────────────────────────────┐
│ 記録を全部消しますか？             │
│                                   │
│ ランキングの記録をすべて消します。 │
│ 元に戻せません。                   │
│                                   │
│ [ キャンセル ]        [ 消す ]     │
└───────────────────────────────────┘
```

- 「キャンセル」は普通のボタンで、最初のフォーカスを置く（誤って消さないため）。「消す」は危険の色（地 `--danger`）のボタン。
- Esc・キャンセルで閉じたら、何も変えない。閉じたら「記録を全部消す」ボタンにフォーカスを戻す。

## 3. 更新のお知らせ（US-0019）

新しい版の準備ができたら、画面の下に固定の帯を出す。

```
┌─────────────────────────────────────┐
│ 新しい版があります      [ 更新 ]    │ ← 地 --surface、上に枠線。下端の安全領域を避ける
└─────────────────────────────────────┘
```

- 出すのはタイトル画面とランキング画面だけ。プレイ画面（結果パネルを含む）にいる間は出さず、タイトル・ランキングに移ったときに出す（操作欄に重ならないようにし、プレイ中に読み込み直さないため）。
- 「更新」を押すと、新しい版に切り替えて読み込み直す。
- 帯は `role="status"`。閉じるボタンは設けない（次に開いたときにも出る）。

## 4. 起動失敗からの復旧（US-0020）

`simple_shogi` の `public/boot.js` と同じ。アプリの画面が出せない状態なので、`boot.js` が最小の画面を直接作る。

```
┌─────────────────────────────────────┐
│ うまく起動できませんでした。         │
│ [ なおす ]                          │
│ 記録は消えません。                   │
└─────────────────────────────────────┘
```

- 1 回目の失敗は、この画面を出さずに自動で読み込み直す。2 分以内に 2 回目の失敗があったら、この画面を出す。
- 色は `boot.js` の中に直接書く（CSS が読めない場合に備えるため。GUI-0001 §3 の `--bg` / `--text` / `--primary` と同じ値）。

## 5. 縦向きのおすすめ（US-0010）

横向きで、ゲーム領域が最小（288 × 384）でしか出せないときに、プレイ画面のゲーム領域の上に 1 行出す。

```
 ⟳ 縦向きでのプレイをおすすめします
```

- 補助の文字（14、`--muted`）。閉じるボタンは設けない（縦向きにすれば消える）。
- タイトル・ランキング画面では出さない（縦スクロールで使えるため）。
