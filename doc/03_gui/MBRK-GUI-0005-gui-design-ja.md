# GUI-0005 ランキング画面

## 1. 画面の形（幅 375）

```
┌─────────────────────────────────────┐
│ [← BACK]  ハイスコアランキング       │ ← 上部のバー（GUI-0001 §5.4）
│                                     │
│ 順位 │ 名前                 │ スコア │ ← 表の見出し（--muted、14）
│ ─────┼──────────────────────┼─────── │
│▌1st  │ TSUKU（あなた）      │  1,250 │ ← 自分の記録：背景 + 左端の帯（--accent）
│▌     │ ✔ CLEAR · 2026/10/23 12:15  │ │ ← 2 段目（--muted、12）
│ ─────┼──────────────────────┼─────── │
│ 2nd  │ HARU                 │    980 │
│      │ ✔ CLEAR · 2026/10/22 21:03  │ │
│ ─────┼──────────────────────┼─────── │
│ 3rd  │ とても長い名前のプレ…│    400 │ ← 長い名前は省略記号
│      │ ✖ GAME OVER · 2026/10/21 …  │ │
│ ─────┼──────────────────────┼─────── │
│  4   │ …                    │    … │
│  …（最大 10 行）                    │
│                                     │
│ ┌ 記録のバックアップ ─────────────┐ │
│ │ [⤓ 記録を書き出す][⤒ 記録を読み込む]│ │
│ │ （結果のメッセージ）            │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

幅 480 未満の画面は常にこの 2 段の形にする（仕様書 §8.4 で認めた形）。表は `table` で作り、列は「順位」「名前・結果・登録日時」「スコア」の 3 つにする。

## 2. 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| BACK | 普通のボタン（arrow-left +「BACK」）。タイトル画面へ。Esc でも同じ | US-0013 |
| 見出し | `h2`「ハイスコアランキング」。`tabindex="-1"` で初期フォーカス | US-0013 |
| 順位 | 1〜3 位は「1st」「2nd」「3rd」（太字・`--accent`）。4 位以下は数字（`--text`）。幅 48 | US-0013 |
| 名前 | 1 段目。1 行で、はみ出す分は省略記号（`text-overflow: ellipsis`）。全文は `title` 属性で見られる（PC はマウスを重ねる、スマホは長押し）。文字は `textContent` で入れる | US-0013 |
| （あなた） | 自分の記録だけ、名前の後ろに「（あなた）」。名前が長くても「（あなた）」は省略しない（名前の部分だけを省略する） | US-0013 |
| 結果・登録日時 | 2 段目（12、`--muted`）。check-circle +「CLEAR」または x-circle +「GAME OVER」、「 · 」、端末のタイムゾーンで `YYYY/MM/DD HH:mm` | US-0013 |
| スコア | 右寄せ、等幅、3 桁区切り。幅 72 | US-0013 |
| 自分の記録の行 | 背景を `--accent` の 12% の色にし、左端に幅 4 の `--accent` の帯を付ける | US-0013 |
| 記録を書き出す | 普通のボタン（download アイコン）。押すと JSON ファイルを保存する。記録が 0 件のときも押せる（空のファイルになる） | US-0014 |
| 記録を読み込む | 普通のボタン（upload アイコン）。押すとファイル選択（`accept=".json,application/json"`）→ 確認ダイアログ（GUI-0006 §2）→ 読み込み | US-0014 |
| 結果のメッセージ | `role="status"`。成功は `--success`、失敗は `--danger`（仕様書 §9.6 の文） | US-0014 |

## 3. 状態ごとの表示

表の場所に、次のどれかを出す。バックアップの欄は、どの状態でも出す（読み込みで記録を戻せるようにするため）。

| 状態 | 表示 |
| --- | --- |
| 記録あり | 表 |
| 0 件 | 「まだ記録がありません」（`--muted`）+ 普通のボタン「タイトルへ戻る」 |
| 読み込み失敗 | x-circle +「ランキングを読み込めませんでした」（`--danger`）+ 普通のボタン「再読み込み」 |

- 保存の読み込みは端末の中で一瞬で終わるので、「読み込み中」の表示は設けない。
- 画面を開くたび、読み込みに成功するたびに、表を作り直す。

## 4. キー操作

| キー | 動き |
| --- | --- |
| Esc | タイトル画面へ（BACK と同じ） |
| Tab の順 | BACK → （0 件・失敗のときのボタン）→ 記録を書き出す → 記録を読み込む |

## 5. 読み上げ

- 表に `caption`（画面には出さない）「上位 10 件の記録」を付ける。列の見出しは `th scope="col"`、各行の順位は `th scope="row"`。
- 自分の記録の行は、「（あなた）」の文字で伝わる（色と帯だけにしない）。
