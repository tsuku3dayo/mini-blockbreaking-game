# GUI-0002 タイトル画面

## 1. 画面の形（幅 375 × 高さ 667）

```
┌─────────────────────────────────────┐
│                                     │ ← 上端の余白
│                                     │
│          B R E A K O U T            │ ← ロゴ（等幅・太字 40）
│     ▬▬ ▬▬ ▬▬ ▬▬ ▬▬                   │ ← 飾りのブロック（5 色）
│                                     │
│  ┌───────────────────────────────┐  │
│  │      ▶ START        [Enter]   │  │ ← 主ボタン（高さ 56）
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │          RANKING              │  │ ← 普通のボタン（高さ 48）
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │         クレジット            │  │ ← 普通のボタン（高さ 48）
│  └───────────────────────────────┘  │
│                                     │
│  ┌ 操作方法 ─────────────────────┐  │
│  │ パドル移動  画面の下をなぞる   │  │
│  │             マウス / ← → ・ A D│  │
│  │ 発射        タップ / クリック  │  │
│  │             / Space            │  │
│  │ 一時停止    一時停止ボタン     │  │
│  │             / P ・ Esc         │  │
│  └───────────────────────────────┘  │
│                                     │
│  [🔊 効果音：オン]                   │ ← トグルボタン（中央寄せ）
│                                     │
│        [ 記録を全部消す ]            │ ← 普通のボタン（中央寄せ、文字は --danger）
│        （結果のメッセージ）          │ ← role="status"（出ていないときは場所を取らない）
│                                     │
│   ⤓ アプリとしてインストールする方法 │ ← リンク風ボタン
│               v1.0.0                │ ← バージョン（補助の文字）
└─────────────────────────────────────┘
```

内容が画面の高さに収まらない場合（小さい画面・文字サイズを大きくした場合）は、縦にスクロールする。

## 2. 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| ロゴ | 見出し `h1`「BREAKOUT」。下にブロックの 5 色を並べた飾り（`aria-hidden`） | US-0001 |
| START | 主ボタン。押すと新しいゲームでプレイ画面へ。初期フォーカス。PC では `Enter` のヒント | US-0001 |
| RANKING | 普通のボタン。ランキング画面へ | US-0001 |
| クレジット | 普通のボタン（RANKING の下）。クレジット画面へ（GUI-0007） | US-0023 |
| 操作方法 | 見出し「操作方法」と、3 行の定義リスト（`dl`）。項目名は `--muted`、説明は `--text`。端末によらず全部の操作を載せる | US-0001 |
| 効果音ボタン | トグルボタン。「効果音：オン」+ sound-on ／「効果音：オフ」+ sound-off。`aria-pressed` はオンのとき `true` | US-0016 |
| 記録を全部消す | 普通のボタン（中央寄せ、文字は `--danger`）。押すと確認ダイアログ（GUI-0006 §2.1）。START・RANKING から離して置き、押し間違えにくくする | US-0022 |
| 結果のメッセージ | `role="status"`。消せたら「記録を消しました」（`--success`）、書き込めなかったら「消せませんでした。もう一度お試しください」（`--danger`）。画面を開き直したら消す | US-0022 |
| インストール方法の入口 | リンク風ボタン「アプリとしてインストールする方法」+ install アイコン。押すとインストール方法のダイアログ（GUI-0006）。インストール済みのアプリとして開いたときは出さない | US-0017 |
| バージョン | `v` + `package.json` の版。補助の文字、中央寄せ | US-0019 |

## 3. キー操作

| キー | 動き |
| --- | --- |
| Enter | START と同じ。ただし、ほかのボタンにフォーカスがあるときは、そのボタンの動作だけ（仕様書 §4.1-9） |
| Tab | START → RANKING → クレジット → 効果音 → 記録を全部消す → インストール方法 の順にフォーカスが移る |

## 4. 読み上げ

- `section` に `aria-labelledby` でロゴの見出しを結ぶ。
- 効果音ボタンは `aria-pressed` で状態を伝える。
