# TC-0016 効果音をオン / オフする

- 対象：[MBRK-US-0016](../02_requirements/MBRK-US-0016-user-story-ja.md)
- テストファイル：`e2e/sound.spec.ts`

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |
| --- | --- | --- | --- | --- |
| TC-0016-01 | オフにすると鳴らない（§12.6-4） | E2E | タイトルで効果音をオフ → START → 発射 | `app:sound` の `launch` が `muted: true` |
| TC-0016-02 | 鳴っている音が止まる（§12.6-4） | 手動 | クリアの音が鳴っている間に効果音ボタンを押す | すぐに音が止まる |
| TC-0016-03 | 開き直しても引き継ぐ（§12.6-5） | E2E | オフ → 読み込み直す | ボタンが「効果音：オフ」 |
| TC-0016-04 | 初めはオン（§12.6-6） | E2E | 保存データが空で開く | 「効果音：オン」、`aria-pressed = true` |
| TC-0016-05 | 2 つのボタンがそろう（§8.7） | E2E | プレイ画面の操作欄でオフ → タイトルへ | タイトルのボタンも「効果音：オフ」 |
| TC-0016-06 | プレイ中に押しても止まらない（§8.3） | E2E | 発射後に操作欄の効果音ボタンを押す | `status = 'playing'` のまま |
| TC-0016-07 | 保存できなくても効く（§8.7） | E2E | `setItem` を例外にして開く → オフ → 発射 | `muted: true` |
| TC-0016-08 | 状態を支援技術に伝える（§8.5） | E2E | オン ⇔ オフ | `aria-pressed` が true ⇔ false |
