# TC-0019 新しい版に自分のタイミングで更新する

- 対象：[MBRK-US-0019](../02_requirements/MBRK-US-0019-user-story-ja.md)
- テストファイル：`e2e/pwa.spec.ts`、`scripts/check-dist.mjs`

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |
| --- | --- | --- | --- | --- |
| TC-0019-01 | バージョンの表示（§12.7-4） | E2E | タイトル画面 | `#version` が `package.json` の `version` と同じ（`v` + 版） |
| TC-0019-02 | バージョン表示の有無 | ビルド検査 | `npm run check:dist` | 通る（`#version` がある） |
| TC-0019-03 | 更新の帯を出す画面 | E2E | 更新の帯を出す処理（`onNeedRefresh`）を `?debug` から呼ぶ → プレイ画面 → タイトル | プレイ画面では見えない。タイトルに戻ると見える |
| TC-0019-04 | プレイ中に切り替わらない・更新ボタン（§12.7-6） | 手動（アップデート時） | 公開中の版を開いて遊んでいる間に、新しい版（`version` を上げたもの）を公開する | 遊んでいる間は画面が読み込み直されない。タイトルに戻ると「新しい版があります」。「更新」で新しいバージョンが表示される |

TC-0019-04 は、v1.0.0 の公開後、最初のアップデート（v1.0.1 以降）を公開するときに行う（2026-10-23 オーナー決定）。v1.0.0 の AC では「確認できなかったこと」に「最初のアップデート時に確認する」と書き、アップデートの AC に結果を残す。
