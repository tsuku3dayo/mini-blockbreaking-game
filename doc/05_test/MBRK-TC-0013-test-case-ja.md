# TC-0013 ランキングで自分の記録を見る

- 対象：[MBRK-US-0013](../02_requirements/MBRK-US-0013-user-story-ja.md)
- テストファイル：`tests/ranking.test.ts`、`tests/format.test.ts`、`e2e/ranking.spec.ts`
- E2E の前提：記録は `addInitScript` で保存データに直接入れる（必要なときだけ画面で登録する）

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |
| --- | --- | --- | --- | --- |
| TC-0013-01 | 同点は先に登録した方が上（§12.4-4） | 単体 | score 同じで createdAt が違う 2 件、createdAt も同じで id が違う 2 件を `compareRecords`・`rankOf` | 先の createdAt が上、同じなら小さい id が上 |
| TC-0013-02 | 登録時の順位と一覧の順位が一致（§12.4-4） | E2E | 同じ点数で 2 回登録する（2 回目は 2 位と表示されるはず） | 登録時「2 位で登録しました」、ランキングでも 2 行目 |
| TC-0013-03 | 「（あなた）」（§12.4-8） | E2E | 登録 → ランキング | その行に「（あなた）」と強調のクラス。ほかの行にはない |
| TC-0013-04 | 0 件・読み込み失敗（§12.4-10） | E2E | 空で開く。`scores` を壊れた JSON にして開く → 直してから「再読み込み」 | 「まだ記録がありません」+「タイトルへ戻る」。「ランキングを読み込めませんでした」+「再読み込み」→ 表が出る |
| TC-0013-05 | 列と順位の表示（§8.4） | 単体・E2E | `rankLabel(1〜4)`。4 件で開く | `1st`・`2nd`・`3rd`・`4`。1〜3 位は強調のクラス |
| TC-0013-06 | 長い名前（§8.4） | E2E | 12 文字の全角の名前と「（あなた）」 | 名前のセルが省略記号で切れ（`scrollWidth > clientWidth`）、`title` に全文。「（あなた）」は見える |
| TC-0013-07 | 結果と日時（§8.4） | 単体・E2E | `formatDateTime('2026-10-23T03:15:00.123Z', 'Asia/Tokyo')`。クリアとゲームオーバーの記録 | `2026/10/23 12:15`。「CLEAR」「GAME OVER」の文字とアイコンがある |
| TC-0013-08 | 横スクロールなし（§8.4） | E2E | `small` プロジェクトで、12 文字の名前の記録 10 件 | `scrollWidth ≤ clientWidth` |
| TC-0013-09 | BACK・Esc・初期フォーカス（§8.4） | E2E | 開く → Esc。開く → BACK | 開いたとき見出しにフォーカス。どちらもタイトル画面へ |
| TC-0013-10 | 開くたびに読み直す（§8.4） | E2E | ランキングを開く → タイトルへ → 保存データに記録を足す → もう一度開く | 足した記録が出る |
