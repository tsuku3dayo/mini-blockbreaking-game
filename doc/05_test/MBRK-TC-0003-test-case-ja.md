# TC-0003 ボールを打ち返し、壁で跳ね返らせる

- テストファイル：`tests/collision.test.ts`、`tests/game.test.ts`
- 前提：速さ 300（段階 0）。ボールの位置・速度は各行で指定

| TC-0003-02 | 端で 60°（§12.1-4） | 単体 | ボール x = 280（右端）・x = 200（左端）、下向き | 右：速度 ≈ (259.81, −150)。左：≈ (−259.81, −150)。打ち返す前の速度を変えても同じ |
| TC-0003-03 | 上向きは押し出すだけ（§5.5-A） | 単体 | ボールがパドル上面に重なり、速度 (0, −300) | `'push'`、y = 594、速度は変わらない |
| TC-0003-04 | 側面・角（§5.5-B） | 単体 | ボール中心 y = 605、パドル左端の外側から重なる | `'side'`、x = パドル左端 − 6、vx = −|vx|、vy は変わらない |
