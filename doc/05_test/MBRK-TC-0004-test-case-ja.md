# TC-0004 ブロックを壊して得点する

- 対象：[MBRK-US-0004](../02_requirements/MBRK-US-0004-user-story-ja.md)
- テストファイル：`tests/collision.test.ts`、`tests/game.test.ts`、`tests/format.test.ts`
- 前提：`createGame()` を `status = 'playing'` にして、ボールの位置・速度を指定

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |
| --- | --- | --- | --- | --- |
| TC-0004-01 | 1 個壊して 10 点 | 単体 | ブロック 32（5 行目・1 列目）の下面に上向きで当てる | `alive[32] = false`、`broken = 1`、ブロック得点 10、出来事 `block`（row 4、count 1） |
| TC-0004-02 | 2 個同時・反射 1 回（§12.1-7） | 単体 | ブロック 32 と 33 の間（x = 72）の下面に上向きで当てる | 2 個とも壊れ、得点 20、vy の符号は 1 回だけ反転（下向きになる）、出来事 `block` の count 2 |
| TC-0004-03 | 代表ブロックの選び方（§5.6-3） | 単体 | 2 個に同じ深さで重なる位置 | ID の小さい方で反射位置を決める |
| TC-0004-04 | 側面・上下面・角（§5.6-4） | 単体 | 横から・上から・角からそれぞれ当てる | 横：vx 反転・x 補正。上：vy 反転・y 補正。角（overlapX = overlapY）：両方 |
| TC-0004-05 | 加速（§12.1-8） | 単体 | `broken` を 9・19・29 にしてから 1 個壊す | 速さが 330・360・390、速度の向き（角度）は壊す前の反射後と同じ、出来事 `speedUp` |
| TC-0004-06 | 段階は下がらない、40 個で 390（§5.8） | 単体 | `broken` 39 → 40 | 段階 3 のまま、速さ 390 |
| TC-0004-07 | 3 桁区切り（§6） | 単体 | `formatNumber(0)`・`(400)`・`(1250)`・`(2200)` | `0`・`400`・`1,250`・`2,200` |
| TC-0004-08 | HUD の文字 | 単体 | 偽の Canvas に `broken = 30` の状態を描く | 「SCORE : 300」を左、「TIME : n」を右に描く |
