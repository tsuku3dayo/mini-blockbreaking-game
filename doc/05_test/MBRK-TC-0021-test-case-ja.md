# TC-0021 画面の読み上げで状況が分かる

- 対象：[MBRK-US-0021](../02_requirements/MBRK-US-0021-user-story-ja.md)
- テストファイル：`e2e/a11y.spec.ts`
- E2E の前提：`#announcer` の文字の変化を `MutationObserver` で記録する（`simple_shogi` と同じやり方）

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |
| --- | --- | --- | --- | --- |
| TC-0021-01 | 代替テキスト（§8.5） | E2E | プレイ画面 | Canvas が `role="img"`、名前「ブロック崩しのゲーム画面」で見つかる |
| TC-0021-02 | 読み上げの文（§8.5） | E2E | `/?debug=1` でブロックを 1 個壊す → 一時停止 → 再開 → クリアさせる | 記録に「スコア 10」「一時停止しました。再開ボタンで再開します」「再開しました」「クリア。スコア …」が順に入る |
| TC-0021-03 | ゲームオーバーの読み上げ | E2E | 落とす | 「ゲームオーバー。スコア n」 |
| TC-0021-04 | トグルの状態（§8.5） | E2E | 一時停止ボタン・効果音ボタン | `aria-pressed` が状態に合う（TC-0009-05、TC-0016-08 と同じ確認） |
| TC-0021-05 | 色だけに頼らない（§8.4、§8.5） | E2E | 結果パネルの見出し、ランキングの結果の列・自分の記録 | 文字（「CLEAR!」「GAME OVER」「CLEAR」「（あなた）」）がある |
| TC-0021-06 | 効果音の出来事が画面か読み上げで分かる（§8.5） | 確認（読み合わせ） | 8 種類の効果音ごとに、対応する画面の変化・読み上げを表にする | 発射（ボールが動く）、パドル・壁（ボールの向き）、ブロック（消える・スコアの読み上げ）、加速（ボールの速さ）、クリア・ゲームオーバー（結果パネル・読み上げ）、登録（メッセージ）。すべてに対応がある |
| TC-0021-07 | キーボードで全ボタン（§8.1） | E2E | 各画面で Tab を押していく | すべてのボタンにフォーカスが届き、フォーカスの輪（`outline`）が見える |
| TC-0021-08 | 動きを減らす（§8.1） | E2E | `reducedMotion: 'reduce'`（既定）で画面を切り替え、結果パネルを出す | 切替え・結果パネルの `transition-duration`・`animation-duration` が 0 |
| TC-0021-09 | 画面の読み上げ機能で使う | 手動 | iPhone の VoiceOver をオンにして、タイトル → プレイ（一時停止・再開）→ 結果 → ランキング | 各ボタンの名前と状態、スコア・一時停止・結果が読み上げられる |
