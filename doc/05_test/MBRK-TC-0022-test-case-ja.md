# TC-0022 非機能（60 fps・入力の遅れ）

- 対象：仕様書 §10 のうち、ユーザーストーリーに入れていない非機能要件
- 種類：手動（実機とブラウザの開発ツール）

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |
| --- | --- | --- | --- | --- |
| TC-0022-01 | スマホで 60 fps（§10） | 手動 | Android の Chrome をパソコンにつなぎ、リモートの開発ツールの「Performance」で記録する。`/?debug=1` で速度段階 3・ブロックを壊し続ける場面を作り、10 秒記録する | フレームの間隔がほぼ 16.7 ms で、長い欠け（50 ms 超）がない |
| TC-0022-02 | iPhone で 60 fps | 手動 | iPhone の Safari をパソコンの Safari の Web インスペクタにつなぐ（Mac がない場合は目視） | 同上。目視の場合は、ボールの動きにカクつきがないこと。どちらで確かめたかを AC に書く |
| TC-0022-03 | パソコンで 60 fps | 手動 | パソコンの Chrome の開発ツールで、TC-0022-01 と同じ場面を記録 | 同上 |
| TC-0022-04 | 入力の遅れ（§10） | 手動 | 実機で指を素早く左右に動かす | パドルが指から遅れて見えない |
