# TC-0022 非機能（60 fps・入力の遅れ）

- 対象：仕様書 §10 のうち、ユーザーストーリーに入れていない非機能要件
- 種類：手動（実機での目視）
- 60 fps は目視で確かめる（2026-10-23 オーナー決定）。開発ツールでの計測は行わない

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |
| --- | --- | --- | --- | --- |
| TC-0022-01 | Android で 60 fps（§10） | 手動（目視） | Android の Chrome で `/?debug=1` を開き、速度段階 3・ブロックを壊し続ける場面を作り、30 秒見る | ボールとパドルの動きがなめらかで、カクつき・止まりがない |
| TC-0022-02 | iPhone で 60 fps | 手動（目視） | iPhone の Safari と、ホーム画面に追加したアプリで、TC-0022-01 と同じ場面を見る | 同上 |
| TC-0022-03 | パソコンで 60 fps | 手動（目視） | パソコンの Chrome で、TC-0022-01 と同じ場面を見る | 同上 |
| TC-0022-04 | 入力の遅れ（§10） | 手動（目視） | 実機で指を素早く左右に動かす | パドルが指から遅れて見えない |

目視での確認なので、AC には「開発ツールでのフレーム間隔の計測はしていない」ことを「確認できなかったこと」に書く。
