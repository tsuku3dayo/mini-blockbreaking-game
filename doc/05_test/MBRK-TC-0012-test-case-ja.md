# TC-0012 スコアを名前つきで登録する

- 対象：[MBRK-US-0012](../02_requirements/MBRK-US-0012-user-story-ja.md)
- テストファイル：`tests/ranking.test.ts`、`tests/storage.test.ts`、`tests/records.test.ts`、`e2e/register.spec.ts`
- E2E の前提：`/?debug=1` で終わらせて結果パネルを出し、500 ms 進める

| 確認 ID | 確かめること | 種類 | 手順・入力 | 期待結果 |

| TC-0012-01 | 前後の空白を除く（§12.4-1） | 単体 | `validateName(' TSUKU ')`、全角空白で囲んだ名前 | `{ ok: true, name: 'TSUKU' }` |
