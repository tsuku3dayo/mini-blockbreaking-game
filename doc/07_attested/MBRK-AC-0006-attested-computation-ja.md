## 3. 確認できなかったこと

- 人の確認はパソコンの Chrome だけ。スマートフォン（タッチ）での操作は、段階 2（WS-0003）で確かめる。
- ポインタを離したことは、Canvas のポインタのキャプチャではなく `window` の `pointerup` で受けている（キャプチャはこのタスクの範囲外で、後のタスクで TD-0003 §3.3 の形にする）。
- 表示サイズは、最大 448 px 幅で、画面の幅に合わせて縮めるだけにした（TASK-0007 で仕様書 §2.1 の高さを含めた計算にする）。
- `play.ts` は、まだ一時停止・結果パネル・効果音・読み上げを持たない（後のタスク）。終了したら暗くして止まるだけ。
- 開いたらすぐプレイ画面になる（TASK-0006 の指示どおり。TASK-0009 でタイトルからに直す）。そのため、仮の E2E `e2e/smoke.spec.ts` を「プレイ画面が開く」に書き換えた。
- `setClock`（TD-0001 §7）は作っていない。E2E の時計は Playwright の `page.clock` で止めた。
