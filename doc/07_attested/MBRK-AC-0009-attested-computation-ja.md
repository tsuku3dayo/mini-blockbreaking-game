## 3. 確認できなかったこと

- Android の実機では確かめていない（AC-0007・0008 §3）。
- タイトル画面の効果音ボタンは、場所だけ空けた（TASK-0018）。
- ランキング画面は骨組み（バーと「まだ記録がありません」）だけ。表・バックアップは TASK-0016。
- 画面の切替えのフェード（150 ms）は CSS のアニメーションで、E2E は `reducedMotion: 'reduce'` で動かしているため、動きそのものは確かめていない。
- アイコンは `src/icons.ts` の形を、起動時に `index.html` の `<span data-icon>` へ入れる形にした（TASK-0007 までに HTML に直接書いていた SVG も置き換えた）。
