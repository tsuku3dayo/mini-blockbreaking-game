## 3. 確認できなかったこと

- Android の実機では確かめていない（AC-0007・0008 §3）。
- 名前の入力欄と REGISTER は、場所だけ用意して隠してある（TASK-0015）。そのため、初期フォーカスは PC・スマホとも見出しにした（GUI-0004 §4 の PC の「入力欄にフォーカス」は TASK-0015）。
- 入力ガード（パネルが出てから 500 ms の間、Enter・Space・タップを無視する）は、まだない（TASK-0012）。E2E は 500 ms 待ってから押している。
- パネルが出たときの読み上げ（「クリア。スコア 1,250」）は、読み上げの仕組みがまだないので入れていない。
- パネルの地を不透明にしたので、パネルの下の暗くした盤面はほとんど見えない（GUI-0004 の「パネルの大きさはゲーム領域と同じ」のとおり、パネルが盤面を覆う）。
- 登場の動き（200 ms）は CSS のアニメーションで、E2E は `reducedMotion: 'reduce'` で動かしているため、動きそのものは確かめていない。
