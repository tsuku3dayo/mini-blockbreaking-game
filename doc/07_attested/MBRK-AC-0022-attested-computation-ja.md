### 2.1 TC-0021-06 効果音と、画面・読み上げの対応

| 効果音 | 画面の変化 | 読み上げ |
| --- | --- | --- |
| 発射（launch） | ボールがパドルを離れて動き出す。「タップ / Space で発射」の案内が消える。TIME が増え始める | —（画面の変化で分かる） |
| パドル（paddle） | ボールの向きが上向きに変わる | — |
| 壁（wall） | ボールの向きが壁の反対向きに変わる | — |
| ブロック（block） | ブロックが消え、SCORE が増える | 「スコア n」 |
| 加速（speedUp） | ボールが速くなる（10・20・30 個目） | 「スコア n」（同じフレームのブロックの読み上げ） |
| クリア（clear） | 結果パネル「CLEAR!」（アイコンつき） | 「クリア。スコア n」 |
| ゲームオーバー（gameOver） | 結果パネル「GAME OVER」（アイコンつき） | 「ゲームオーバー。スコア n」 |
| 登録（register） | 「n 位で登録しました」などのメッセージ（`role="status"`） | メッセージが `role="status"` で読み上げられる |

そのほか：

- 単体 101 件・E2E 235 件、`npm run verify` は成功。
- 実装：
  - `src/announce.ts`：通知領域に文を出す。同じ文が続いても読み上げられるよう、いったん空にしてから次のフレームで入れる（TD-0003 §6）。同じフレームに何度も呼ばれたら最後の文だけ。
  - `src/play.ts`：ブロックを壊したフレームでスコア、一時停止・再開・終了で読み上げる（仕様書 §8.5）。`src/main.ts`：`createAnnounce()` をプレイ画面に渡す。
  - `src/style.css`：動きを減らす設定のときの時間を `0.01ms` から `0s` にした（TC-0021-08 の期待どおりにするため。見た目の違いはない）。
- Tab の順・フォーカスの輪・`aria-*` は、各タスクで作ったものが GUI-0001 §5・§6 のとおりだったので、ほかの作りは直していない。
- 最初、TC-0021-07 のランキング画面で失敗した。見出し（初期フォーカス）は BACK より後ろにあるので、見出しから Tab を押すと BACK を飛ばして「書き出す」に進む（ブラウザの正しい動き）。テストの考え違いだったので、Shift+Tab で BACK に戻る形に直した。フォーカスを外しても、ブラウザは Tab の起点を覚えていたため、外す形では確かめられなかった。

## 3. 確認できなかったこと

- 名前を変えたあとの代替テキストを、VoiceOver で聞いては確かめていない（自動テストの TC-0021-01 で確認）。
- クリアのフレームでは、そのフレームのスコアの読み上げは出さず、「クリア。スコア n」だけを出す（同じフレームの最後の文だけを出すため）。スコアは終了の文に含まれる。
- タイトル画面の「記録を消しました」と、ランキング画面の結果のメッセージは、空のときは `display: none` にしている。出たときに読み上げない支援技術があるかは、TC-0021-09 の流れ（タイトル → プレイ → 結果 → ランキング）に「記録を全部消す」・バックアップが入っていないため、確かめていない。
