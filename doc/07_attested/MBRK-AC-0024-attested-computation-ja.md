| TC-0007-10 | E2E | 操作空間で押して 20 動かして離すと `ready` のまま、押して 5 動かして離すと `playing`。ブラウザの本物のタッチ（`touchscreen.tap`）でも、操作空間のタップで発射し、パドルが x ≈ 144 に合う | 成功 |

  - `index.html`：Canvas と操作欄の間に `#control-area`（`aria-hidden`、案内の文字）。タイトル画面の操作方法を「画面の下をなぞる」に。

  - `src/input.ts`：`createInput` に操作空間を渡し、`pointerdown`・`lostpointercapture`・`contextmenu` を Canvas と同じに付ける。捕まえるのは押した要素。位置の変換は Canvas の外形のまま。
  - `src/play.ts`：`matchMedia('(pointer: coarse)')` で操作空間を出し分け、出すときは `controlsHeight` に 104 を足す。`change` で合わせ直す。
  - `src/config.ts`：`CONTROL_AREA_HEIGHT = 96`（仕様書 v1.2 §11）。

### 2.1 結果パネルの間は操作空間を出さない修正（2026-10-25）

WS-0009 の手動確認で、オーナーから「GAME OVER・CLEAR の画面に操作空間が出ている。出ないように」と指示を受けた。GUI-0003 を v1.3 に直し（再承認待ち）、ブランチ `fix/0024-hide-control-area-on-result` で直した。

| 確認 ID | 種類 | 確かめたこと | 結果 |
| --- | --- | --- | --- |
| TC-0007-14 | E2E | ゲームオーバーで終える → 操作空間が見えず、ゲーム領域の外形はプレイ中と同じ → RETRY でまた見える → クリアで終える → 見えず、外形は同じ | 成功 |

- 実装（`src/play.ts`）：終了の処理で操作空間を隠す。表示サイズの計算では、隠していても操作空間の高さを引いたままにした（結果パネルの間にゲーム領域が大きくならないように）。`start()` で出し直す。
- 単体 95 件・E2E 187 件、`npm run verify` は成功。375 × 667 のスクリーンショットで、結果パネルのすぐ下に操作欄が来て、操作空間がないことを確かめた。
- PR #46 の CI（`check`・`e2e`）は緑。2026-10-25 にマージ。
